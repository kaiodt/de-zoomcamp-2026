# Module 1: Containerization and Infrastructure as Code

## Overview

This module focuses on the fundamentals of containerization and Infrastructure as Code (IaC). It teaches how to use Docker to containerize applications and Terraform to manage cloud infrastructure.


## Prerequisites

- [Docker](https://docs.docker.com/get-docker/)
- [Terraform](https://developer.hashicorp.com/terraform/downloads)
- [Google Cloud Platform (GCP) Account](https://cloud.google.com/)


## Docker and Postgres

- **Docker Compose**: Orchestrate multiple containers including Postgres and pgAdmin.
- **Data Ingestion**: Build a Python script to ingest data into a Postgres database.
- **Network**: Connect containers within a shared Docker network.


## Infrastructure as Code with Terraform

- **GCP Setup**: Configure service accounts and authentication.
- **Resources**: Provision Google Cloud Storage (GCS) buckets and BigQuery datasets.
- **Variables**: Use `variables.tf` to parameterize infrastructure configurations.
