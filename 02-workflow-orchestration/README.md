# Module 2: Workflow Orchestration

## Overview

This module focuses on the fundamentals of workflow orchestration. It teaches how to use **Kestra** to create and manage data pipelines, leveraging both local and cloud-based resources.


## Prerequisites

- [Docker](https://docs.docker.com/get-docker/) installed and running.
- [Google Cloud Platform (GCP) Account](https://cloud.google.com/) for cloud integrations.
- [Google AI Studio API Key](https://aistudio.google.com/app/apikey) for Gemini AI features.


## Key Concepts

### Workflow Orchestration with Kestra

- **Declarative YAML**: Define entire workflows using a simple and powerful YAML syntax.
- **Embedded VS Code**: Edit and manage flows directly within the Kestra UI.
- **Plugins**: Leverage a rich ecosystem of plugins for GCP, Postgres, AI, and more.


### Data Pipelines (ETL/ELT)

- **Data Ingestion**: Automate the process of fetching data from APIs and loading it into storage.
- **Cloud Integration**: Sync local data with Google Cloud Storage and BigQuery.
- **Scheduling and Triggers**: Run workflows on a schedule or trigger them based on external events.


### AI Integration

- **Gemini AI**: Incorporate generative AI into your workflows for tasks like data analysis or automated reporting.
