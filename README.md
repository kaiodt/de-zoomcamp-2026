# Data Engineering Zoomcamp 2026

This repository contains the materials and homework assignments for the [Data Engineering Zoomcamp 2026](https://github.com/DataTalksClub/data-engineering-zoomcamp/tree/main) cohort, organized by [Alexey Grigorev](https://github.com/alexeygrigorev) and [DataTalksClub](https://datatalks.club/).

## Course Structure

- [Module 1: Containerization and Infrastructure as Code](./01-docker-terraform) (Docker, Terraform)
- [Module 2: Workflow Orchestration](./02-workflow-orchestration) (Kestra)
- [Module 3: Data Warehouse](./03-data-warehouse) (BigQuery)
- [Module 4: Analytics Engineering](./04-analytics-engineering) (dbt, DuckDB)
- [Module 5: Data Platforms](./05-data-platforms) (Bruin, DuckDB)
